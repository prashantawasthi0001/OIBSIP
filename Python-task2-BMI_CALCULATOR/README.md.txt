# BMI Calculator

## About

This is a simple Python project that calculates a person's Body Mass Index (BMI).

## Features

* Enter weight
* Enter height
* Calculates BMI
* Shows BMI result
* Simple and easy-to-use GUI

## Technologies Used

* Python
* Tkinter

## How to Run

1. Install Python.
2. Open the project folder.
3. Run the program:

```bash
python bmi_calculator.py
```

## Formula

```text
BMI = Weight (kg) / Height² (m)
```

## Example

```text
Weight: 60 kg
Height: 1.70 m
BMI: 20.76
```
